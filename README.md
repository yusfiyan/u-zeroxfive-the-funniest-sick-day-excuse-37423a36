A single one-line sick-day excuse, under 200 characters: a pulled muscle from sneezing, horizontal until further notice — half believable, fresh (no fever, no dog, no dead grandmother), with the twist landing at the end, in the voice of a real text to a boss.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else.
